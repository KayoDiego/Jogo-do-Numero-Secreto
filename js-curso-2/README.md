# 🎯 Jogo do Número Secreto

Este é um projeto simples feito durante o curso de JavaScript da Alura. A proposta é criar um jogo interativo onde o jogador deve adivinhar um número secreto escolhido aleatoriamente pelo sistema.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 🧠 Como funciona

* O sistema gera um número aleatório entre 1 e 100.
* O jogador tem um número limitado de tentativas para adivinhar o número.
* A cada tentativa, o sistema informa se o número digitado é maior ou menor que o número secreto.
* Ao acertar, o jogo exibe uma mensagem de sucesso e permite reiniciar.

1. Clone este repositório:


   ```bash
   cd Jogo-do-Numero-Secreto/js-curso-2
   ```

3. Abra o arquivo `index.html` em seu navegador preferido.
